# bxSites content-authoring guide - The Human Toolkit for the AI Era

Auto-generated by `bxSites new`/`bxSites agents:sync` - refresh anytime with
`bxSites agents:sync` after a bx-sites upgrade. Edit freely OUTSIDE the
`bxsites:agents:start`/`end` markers above/below; a sync only replaces what's
between them.

## Project shape

- Content lives under `src/**/*.md` - plain CommonMark with a
  YAML-style frontmatter block. Folder/file nesting becomes the site nav and
  URL structure automatically (`src/guides/setup.md` ->
  `/guides/setup/`). Link to other pages with a relative `.md` path
  (`[Setup](guides/setup.md)`) - rewritten to a pretty URL at build time.
- `.bxm` files are theme templates only (this project's theme: `bootstrap`)
  - never page content. Don't edit them unless you're customizing the theme
  itself (`bxSites theme:new --theme=bootstrap` ejects it to `src/.theme/`).
- `site/` is generated build output - never hand-edit it, never treat it as a
  source of truth.
- Reserved folders inside `src/` (not scanned as pages):
  `assets/`, `blog/`, `i18n/`, `versions/`, `includes/`, `.theme/`, `.themes/`.

## Frontmatter keys

| Key | Purpose |
|---|---|
| `title` | Page/nav title (else derived from the filename) |
| `order` | Sort position among sibling pages (lower first) |
| `hidden` | `true` builds the page but excludes it from nav + search |
| `description` | Meta/social-card text (falls back to `summary`, then an excerpt) |
| `summary` | One-line lead-in shown on the page itself |
| `tags` | Array - renders as badges, feeds `/tags/`, boosts search |
| `icon` | Emoji, a named icon (`rocket`), or `custom:my-icon` |
| `ogImage` | Per-page social-card image override |
| `toc` | `false` hides the on-page "On this page" outline (default `true`) |
| `layout` | Render through a named `.bxm` instead of the theme's default |

Blog posts (`src/blog/`) add `date`/`authors`/`categories`/`draft` -
scaffold one with `bxSites post:new --title="..."` rather than by hand.

## Content block directives

Syntax: `::: name "Optional Title" key="value" :::` (self-closing) or
`::: name key="value"` ... body ... `:::` (block). Blocks nest freely.

| Directive | Syntax | Use for |
|---|---|---|
| `expandable` | `::: expandable "Title" open="true"` ... `:::` | Collapsible `<details>` section |
| `cards` / `card` | `::: cards` -> `::: card title="" icon="" href=""` | Link-card grid |
| `columns` / `column` | `::: columns` -> `::: column width="50%"` | Side-by-side layout |
| `stepper` / `step` | `::: stepper` -> `::: step "Title" color="success"` | Numbered steps |
| `image-gallery` / `image` | `::: image-gallery columns="3"` -> `::: image src="" alt=""` | Lightbox gallery |
| `file` | `::: file src="assets/spec.pdf" title="..." :::` | Download card |
| `button` / `buttons` | `::: button "Label" href="..." style="primary" :::` | Call-to-action link |
| `embed` | `::: embed url="..." :::` | YouTube/Vimeo/CodePen/Figma/etc. |
| `page-link` | `::: page-link href="../other.md" :::` | Link card, auto-pulls target frontmatter |
| `link-preview` | `::: link-preview url="..." title="..." :::` | External link card, manual fields |
| `prompt` | `::: prompt description="..." expanded="preview"` ... `:::` | Copyable AI-prompt box |
| `updates` / `update` | `::: updates` -> `::: update date="YYYY-MM-DD"` | Changelog list + feed.xml |
| `include` | `::: include src="includes/notice.md" :::` | Splice raw markdown from another file |
| `conditional` / `audience-switcher` | `::: conditional key="plan" value="pro"` ... `:::` | Client-side variant switching |
| `course` | `::: course id="getting-started" :::` | Numbered lesson index from `src/data/courses.yaml` |
| `for` | `::: for item in data.products` ... `:::` | Loop over `src/data/*.yaml|json` |
| `if` / `elseif` / `else` | `::: if data.flags.x` ... `::: else` ... `:::` (ONE closing `:::` for the whole chain) | Conditional content |
| `pagebreak` | `::: pagebreak :::` | Print/PDF page break only |

Cloud/Premium (require a bxSites Cloud plan with the feature enabled - the
block always renders locally, but only *works* once published there):

| Directive | Syntax | Notes |
|---|---|---|
| `contact-form` | `::: contact-form id="..." fields="name:text,email*:email,message:textarea" :::` | `fields` is `name:type` pairs, `*` before `:` marks required; types: text/email/textarea |
| `cloud` | `::: cloud slug="press/release1" :::` | Bakes a bxSites Cloud content block into the page at build time |

Reader comments are not a bx-sites feature yet - don't use a `::: comments :::`
directive, it doesn't exist.

## Workflow

```
bxSites page:new --path=guides/new-page --title="New Page"   # scaffold a page
bxSites serve                                                 # live preview, http://localhost
bxSites lint                                                  # pre-build content checks
bxSites build                                                 # render src/**/*.md -> site/
bxSites publish                                               # ship to bxSites Cloud
```
